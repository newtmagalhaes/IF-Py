- média aritmética ponderada

- média harmônica: $ X_h = \dfrac{n}{\frac{1}{x_1} * \frac{1}{x_2} * \dots * \frac{1}{x_n}} $

- média geométrica: $ X_m = \sqrt[n]{x_1 * x_2 * \dots * x_n} $
